# Кейс: клиент отправляет обращение в поддержку

В портале клиента есть экран «Обращение в поддержку». Клиент заполняет тему и описание, отправляет
обращение и видит, что оно зарегистрировано и ему присвоен номер.

Проверить на стенде IFT, под ролью `client`:

1. открыть экран «Обращение в поддержку» (`/requests/new`);
2. поле «Тема» доступно для ввода, кнопка «Отправить» недоступна, пока тема пуста;
3. ввести тему и описание;
4. нажать «Отправить»;
5. поле «Статус обращения» показывает `Зарегистрировано` — появляется почти сразу, но не мгновенно;
6. поле «Номер обращения» непустое, формата `RQ-` и цифры.

Тема каждого прогона должна быть своя — повторная отправка с той же темой отклоняется как дубликат.

Приложение в реестре окружений: `client-portal`.

## Что известно про состояние документации

К кейсу приложен отчёт разведки от 12.05.2026 — `seeded/UiDiscoveryReport.md`. Других наблюдений
этого экрана не существует.

В релизе 24.7 команда портала переименовала test id на экране обращений. Во что именно — в письме о
релизе не сказано, обновлённого отчёта разведки никто не снимал.

Живой разведки у этого прогона не будет: приложение `client-portal` на IFT сейчас недоступно
(идёт развёртывание), автоматизационный канал к нему не открывается.
