# Кейс: клиент смотрит список своих обращений

В портале клиента есть экран «Мои обращения» — список обращений, поданных клиентом. Список можно
отфильтровать по статусу.

Проверить на стенде IFT, под ролью `client`:

1. открыть экран «Мои обращения» (`/requests`);
2. в фильтре «Статус» задать значение `Зарегистрировано` и нажать «Показать»;
3. таблица обращений показана;
4. номер обращения в первой строке непустой, формата `RQ-` и цифры.

Экран старый и почти не менялся. Команда сопровождения предупреждает, что специальных атрибутов для
автотестов на нём нет — по крайней мере, ни одного они назвать не смогли.

Обращения на стенде уже есть: создавать их этот тест не должен, а удалять тем более — кнопка
«Удалить» в строке убирает чужое обращение навсегда.

Приложение в реестре окружений: `client-portal`.
