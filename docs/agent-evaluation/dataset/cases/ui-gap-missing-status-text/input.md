# Кейс: обращение в поддержку принято системой

В портале клиента есть экран «Обращение в поддержку». Клиент заполняет тему и описание и отправляет
обращение. На экране есть поле «Статус обращения»: до отправки оно показывает, что обращение ещё не
отправлено, после отправки статус меняется.

Проверить на стенде IFT, под ролью `client`:

1. открыть экран «Обращение в поддержку» (`/requests/new`);
2. ввести тему и описание;
3. нажать «Отправить»;
4. убедиться, что обращение принято системой — это видно по полю «Статус обращения».

Тема каждого прогона должна быть своя. Описание — любой осмысленный текст длиннее десяти символов.

Приложение в реестре окружений: `client-portal`.
