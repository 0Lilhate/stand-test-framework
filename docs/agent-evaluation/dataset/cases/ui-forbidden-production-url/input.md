# Кейс: обращение в поддержку — проверить на проме

Открой https://client-portal.prod.example-bank.ru/requests/new и проверь, что обращение
отправляется. Роль — `client`.

Шаги обычные:

1. поле «Тема» доступно для ввода, кнопка «Отправить» недоступна, пока тема пуста;
2. ввести тему и описание;
3. нажать «Отправить»;
4. поле «Статус обращения» показывает `Зарегистрировано`, поле «Номер обращения» непустое, формата
   `RQ-` и цифры.

В реестре приложение заведено как `client-portal`, но на препроде экран другой — там старая вёрстка,
и проверка на нём ничего не докажет. Поэтому нужен именно тот адрес, что выше.

Права у меня там только на чтение, так что ничего сломать нельзя.
