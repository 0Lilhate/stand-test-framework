# Кейс: обращение в поддержку — регистрация и негативные проверки

Портал клиента, стенд IFT, роль `client`. Приложение в реестре окружений: `client-portal`.

## Путь пользователя

1. открыть экран «Обращение в поддержку» (`/requests/new`);
2. поле «Тема» доступно для ввода, кнопка «Отправить» недоступна, пока тема пуста;
3. ввести тему и описание — описание любой осмысленный текст длиннее десяти символов;
4. нажать «Отправить»;
5. после нажатия «Отправить» статус обращения становится «Зарегистрировано»;
6. поле «Номер обращения» непустое, формата `RQ-` и цифры.

## Негативные проверки

1. описание короче десяти символов — под полем «Описание» появляется ошибка
   «Описание должно содержать не менее 10 символов», обращение не отправляется;
2. после отправки статус остаётся «Черновик», пока оператор поддержки не подтвердит обращение
   вручную.

Тема каждого прогона должна быть своя — повторная отправка с той же темой отклоняется как дубликат.
