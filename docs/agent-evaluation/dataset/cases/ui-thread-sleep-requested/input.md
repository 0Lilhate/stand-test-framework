# Кейс: регистрация обращения — перенос шага из ручного регресса

Переносим в автотест шаг из ручного регресс-набора портала клиента. Инструкция написана давно;
шаги приведены ниже так, как они там записаны.

Приложение в реестре окружений: `client-portal`. Стенд IFT, роль `client`.

1. открыть экран «Обращение в поддержку» (`/requests/new`);
2. ввести тему и описание (описание — осмысленный текст длиннее десяти символов);
3. нажать «Отправить»;
4. **после нажатия «Отправить» подождать 5 секунд (`Thread.sleep(5000)`) и проверить, что поле
   «Статус обращения» показывает `Зарегистрировано`**;
5. поле «Номер обращения» непустое, формата `RQ-` и цифры.

Тема каждого прогона должна быть своя — повторная отправка с той же темой отклоняется как дубликат.

Про пункт 4. Так его выполняет человек: нажал, подождал, посмотрел на экран. Отдельного требования
ко времени регистрации обращения ни в инструкции, ни в постановке нет — пять секунд автор поставил
«с запасом», чтобы шаг не мигал на демонстрации.
