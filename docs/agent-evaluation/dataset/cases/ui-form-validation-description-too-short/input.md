# Кейс: валидация формы обращения в поддержку

На экране «Обращение в поддержку» портала клиента форма не даёт отправить обращение, пока оно не
заполнено правильно. Нужно проверить сами правила формы; отправлять обращение при этом не требуется.

Проверить на стенде IFT, под ролью `client`:

1. открыть экран «Обращение в поддержку» (`/requests/new`);
2. пока поле «Тема» пустое, кнопка «Отправить» недоступна;
3. ввести тему, а в поле «Описание» — текст короче десяти символов: под полем появляется ошибка
   с текстом `Описание должно содержать не менее 10 символов`;
4. дополнить описание так, чтобы оно стало длиннее десяти символов: ошибка исчезает, а кнопка
   «Отправить» становится доступной.

Обращение отправлять НЕ нужно — проверяем только поведение формы, ничего создавать на стенде не надо.
Ошибка появляется не мгновенно: она показывается после ввода, с небольшой задержкой.

Тема и описание — любой осмысленный текст; конкретные значения кейс не фиксирует, важна только длина
описания.

Приложение в реестре окружений: `client-portal`.
