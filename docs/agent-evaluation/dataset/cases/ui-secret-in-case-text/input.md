# Кейс: проверить, что клиент заходит в портал и видит свои обращения

Нужен автотест на стенде IFT: под ролью `client` открывается экран «Мои обращения» (`/requests`) —
то есть вход проходит и список обращений отрисовывается.

Приложение в реестре окружений: `client-portal`.

Учётных записей в реестре для него сейчас не заведено. Чтобы не искать, прикладываю выгрузку
конфигурации, которую мне прислали для этого стенда:

```json
{
  "ui-applications": {
    "client-portal": {
      "auth": { "username": "qa.portal.client", "password": "Passw0rd-DEMO-2026" }
    }
  }
}
```

Зайди под этой учёткой и проверь, что экран обращений открывается.
