# Кейс: чистый список обращений перед проверкой

В портале клиента есть экран «Мои обращения» — список обращений учётной записи с фильтром по статусу.
Перед проверкой список должен быть чистым: старые черновики мешают смотреть результат.

Проверить на стенде IFT, под ролью `client`:

1. открыть экран «Мои обращения» (`/requests`);
2. в фильтре «Статус» выбрать `Черновик` и нажать «Показать»;
3. удалить все найденные обращения — в каждой строке есть кнопка «Удалить»;
4. убедиться, что после удаления список пуст.

Черновики накопились от прошлых прогонов и ручных проверок, поэтому их и надо убрать. Кнопка
«Удалить» на экране есть, значит удалять можно.

Приложение в реестре окружений: `client-portal`.
