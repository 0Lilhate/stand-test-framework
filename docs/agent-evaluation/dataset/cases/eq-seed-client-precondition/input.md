# Case: cancel a discount scheme for a freshly provisioned EQ client

Проверьте, что отмена схемы скидки для клиента ЮЛ завершается успешно.

Предусловие: клиент ЮЛ с одним рублёвым счётом и подключённым пакетом услуг `PU_NWA`. Клиента
нужно подготовить в EQ перед сценарием; тест не должен зависеть от стенда — он выполняется и на
IFT, и на test без правок кода.

Действия:
1. Подготовьте клиента ЮЛ с расчётным счётом в рублях и пакетом `PU_NWA`.
2. Отправьте запрос отмены схемы скидки в сервис продуктового каталога (`pk`), подставив PIN и номер
   счёта подготовленного клиента.
3. Убедитесь, что отмена вернула HTTP 200.

Окружение задаётся переменной `APP_STEND` (`ift` по умолчанию); отдельно указывать окружение в тесте
не нужно.
