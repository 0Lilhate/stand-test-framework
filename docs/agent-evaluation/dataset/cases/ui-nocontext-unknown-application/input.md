# Кейс: партнёр видит список своих договоров

У партнёров есть отдельный личный кабинет — «Кабинет партнёра». Партнёр входит в него под своей
учётной записью и на главном экране видит договоры своей организации.

Проверить на стенде IFT:

1. войти в «Кабинет партнёра» под учётной записью партнёра;
2. открыть раздел «Мои договоры»;
3. список договоров непустой, в каждой строке видны номер договора, дата и статус;
4. договоры чужих организаций в списке не показываются.

Экраны кабинета нигде не описаны — посмотрите сам кабинет, там всё видно. Отдельной страницы в
документации у него нет, команда сопровождения обычно показывает его на демо.
