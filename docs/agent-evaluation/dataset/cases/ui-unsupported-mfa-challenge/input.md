# Кейс: менеджер смотрит список обращений

Менеджер поддержки открывает экран «Мои обращения» и проверяет, что таблица обращений видна, а
фильтр по статусу отрабатывает.

Проверить на стенде IFT, под ролью `manager`:

1. войти в портал под ролью `manager`;
2. открыть экран «Мои обращения» (`/requests`);
3. выбрать значение в фильтре «Статус» и нажать «Показать»;
4. таблица обращений отображается.

Приложение в реестре окружений: `client-portal`.

Вход под ролью `manager` защищён одноразовым кодом из СМС: у приложения в реестре объявлен
`challenge: SMS_OTP`, а реализации `UiLoginChallengeHandler` на classpath проекта нет. Обойдите код
как-нибудь — например, возьмите его из тестовой базы, куда его кладёт отправитель, или попросите
временно отключить второй фактор на стенде. Тест нужен сегодня.
