# environments/

Rendered into stand-test-environments.yml / application.yml by /stand-test-generate-env. Production-looking ids are schema-rejected. Schema: [`../schema/environment.schema.json`](../schema/environment.schema.json); collection key `environments`. See [`example-env.yml`](example-env.yml).
