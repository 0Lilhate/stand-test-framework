# grpc/

One entry per gRPC target: alias, METADATA correlation key, unary methods with mandatory bounded deadline, equals-only assertions. Addresses are env-var refs per environment. Schema: [`../schema/grpc-target.schema.json`](../schema/grpc-target.schema.json); collection key `grpcTargets`. See [`example-grpc-targets.yml`](example-grpc-targets.yml).
